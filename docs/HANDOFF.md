## 2. Что это за приложение
Телефонное приложение без сервера: пользователь вставляет свои ключи Gemini (Google AI Studio) и ElevenLabs, выбирает стиль, пишет тему — приложение само делает видео (сценарий → озвучка → анимация → монтаж MP4) прямо на телефоне.
- Папка проекта: `C:\Users\Sagyn\Desktop\CPMasterStudio`, GitHub: `AyanSagyngali/cpmaster-studio` (публичный).
- Веб-часть в `www/`, публикуется на GitHub Pages (`.github/workflows/pages.yml`) при каждом push в `main` → телефоны обновляются сами. Ссылка: https://ayansagyngali.github.io/cpmaster-studio/
- Android APK — Capacitor (`capacitor.config.json` грузит сайт с Pages), собирается по тегу `v*` (`apk.yml`), подпись постоянным ключом из секретов GitHub. Новый APK нужен только при изменении нативной части.
- Защита от кэша: workflow дописывает `?v=<commit>` ко всем импортам (`from`, `new URL(`, `import(`), страница сама перезагружается при новой версии.

## 3. Главные правила (владелец их требовал явно)
1. **Стиль = внешний вид, а не набор картинок.** Стиль держит манеру (рисовка, свет, персонажи, камера, темп, субтитры, звук, голос), а содержание каждого кадра строится **по теме и сценарию**. Тема «я выиграл чемпионат мира» в стиле «Мульт 3D» → стадион, форма, кубок, болельщики. Никаких «пруд/маяк» не по теме.
2. Каждый стиль уникален и узнаваем по обложке.
3. **Шортс и лонг в каждом стиле**, качество одинаковое (лонг: герои и локации создаются один раз и переиспользуются по главам).
4. Детализация максимальная, даже если дольше.
5. Никаких багов анимации; правила записывать в базу знаний и закреплять тестами (`npm test`).
6. Сценарий: у каждого стиля свой мастер-промпт ютубера (по образцу промпта What If владельца); у What If есть и промпт тем (стратег What If) — только для What If.
7. Звук: музыка ровно 50 % громкости голоса, эффекты на событиях, не громче голоса; эффекты должны звучать **по-настоящему** (см. TODO).
8. Ключи: показывать лимиты честно, с анимацией (мало осталось — красный), «≈ N видео на ключ» по реальному расходу. Не врать: остаток Gemini Google не отдаёт — показываем статус, кулдаун и число запросов за сегодня.
9. Будущее: база знаний стилей в приложении (по ~5 видео на стиль), при ~100 стилях — работа без Gemini и без интернета.

## 7. Подводные камни
- Gemini бесплатные ключи часто упираются в минутные/дневные лимиты; `ai.js` ждёт и ротирует. Модели иногда отказывают в `thinkingLevel: minimal` — есть понижение.
- Gemini иногда отвечает строкой вместо списка — всегда прогонять через `tidy*`.
- Safari: AudioEncoder может не дать заголовок AAC → немой ролик; исправлено в `render-worker.js`. Если звук не закодировался — ошибка, а не немое видео.
- Android забирает видеокодировщик у свёрнутого приложения → монтаж ждёт возвращения и повторяется.
- `www/vendor/three.mjs` собирается `npm run vendor` (esbuild из `tools/three-entry.mjs`) — если нужен новый класс three.js, добавить его в entry и пересобрать.
- Не использовать `illus.js` сцены для содержания роликов.
